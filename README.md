# Invictus Agenda

Sistema de gerenciamento de agendamentos desenvolvido para demonstrar uma aplicação web moderna, organizada e responsiva.

## Funcionalidades

* Dashboard com resumo dos agendamentos
* Cadastro e visualização de clientes
* Lista de serviços disponíveis
* Gerenciamento de agendamentos
* Página de configurações
* Interface com tema escuro e detalhes em dourado
* Navegação entre páginas

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
